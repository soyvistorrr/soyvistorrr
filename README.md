### 🚀 Featured Engineering Projects

#### 🏍️ [Moto Candela Platform & Admin](https://github.com/soyvistorrr) *(Team Project - GitLab)*
> **Role: Frontend Lead & UI/UX Engineer**  
> Enterprise-grade e-commerce and inventory administration platform built with a modern, reactive stack.
- **Frontend Architecture:** Built with **Next.js 13+, TypeScript, Tailwind CSS, Radix UI / shadcn/ui, Zustand, and TanStack Query**.
- **Quality Assurance & Testing:** Robust testing strategy combining **Playwright** for full end-to-end user flows and **Jest / Testing Library** for component unit testing.
- **Cross-Functional Collaboration:** Coordinated frontend development and sprint deliverables, seamlessly integrating client views with a containerized **Django REST Framework / PostgreSQL** backend hosted on Google Cloud Platform (GCP).

#### 👁️ [SecureVision API — PostgreSQL & Vector Similarity Search](https://github.com/soyvistorrr/securevision-api) *(Advanced Database Project - USB)*
> **Role: Backend & Database Developer**  
> High-performance RESTful API for video surveillance monitoring, real-time analytics, and semantic object similarity search.
- **Core Technologies:** Python, FastAPI, Pydantic v2, Psycopg 3, PostgreSQL, `pgvector`, Alembic, Docker Compose.
- **Engineering Highlights:**
  - Implemented vector similarity search with the **`pgvector`** extension, performing cosine distance queries over 512-dimensional feature embeddings.
  - Built analytical endpoints for time-window traffic metrics, alerts aggregation, and zone monitoring.
  - Automated schema migrations via **Alembic**, packaged the entire environment with **Docker Compose**, and engineered a bulk CSV ingestion pipeline with transactional validation.

#### 🗳️ [Sistema de Votaciones Estudiantiles USB (2025)](https://github.com/soyvistorrr/elections-integration) *(Production University System)*
> **Role: Core Developer & Security Refactoring**  
> Automated, real-time voting and tallying system for the Federation of Student Centers (FCEUSB) and university representative bodies.
- **Core Technologies:** TypeScript, Google Workspace Engine, Secure Identity Verification.
- **Key Features:** Real-time electoral roll validation, anti-fraud single-vote mechanism, multi-campus election support (Sartenejas and Litoral), and career/cycle-based ballot filtering.

#### 🏛️ [Rupestre Vision — Computer Vision & Mobile App](https://github.com/soyvistorrr) *(Applied AI / MaaS)*
> **Role: AI & Mobile Developer**  
> Automatic detection and classification of Venezuelan rock art manifestations using deep learning.
- **Technologies:** Python, YOLOv8, Roboflow, React Native (Expo Go), Model-as-a-Service (MaaS).
- **Aporte:** Fine-tuned YOLOv8 object detection models, deployed a cloud MaaS inference service, and built an interactive mobile application for live capture, filtering, and bounding box inspection.
